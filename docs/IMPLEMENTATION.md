# Club シルクロード 実装メモ

2026年10月28日。`LP制作計画.md`に基づいてローカルのAstroプロジェクトに実装。

## 実装内容

- 全面の生成ヒーロー、公式ロゴ、短いコピー。
- 営業時間・最寄り駅・定休日の案内。
- 提供写真7枚を、店内、ドリンク、イベント、入口に配置。
- セット料金、延長、追加料金、飲み放題対象、女性半額条件、税の注記。
- メニュー参考画像をもとにしたドリンク・おつまみの文字一覧とカテゴリー開閉。
- 料金・メニュー原本7枚の拡大表示。写真の拡大、前後切り替え、画像のズーム、元画像へのリンク。
- Googleマップの遅延読み込みと経路リンク、実際の建物入口の写真。
- 電話・LINE・Instagramの導線。スマートフォンでは電話・LINEの固定バー。
- GSAP / ScrollTriggerの表示・パララックス演出。PCのホイール操作にLenisを使用。
- 動きを減らす設定、ネイティブdialog、キーボード操作、フォーカス復帰、JavaScript未動作時のリンクを考慮。
- 日本語メタ情報、既存OGP、ファビコン、提供情報に基づくLocalBusiness構造化データ。

## 更新する場所

- 店舗情報・SNS・料金・メニュー・写真対応：`src/data/silkroad.ts`

## 情報の取り扱い

1. 瓶ビールは資料間で価格が異なるため、文字メニューでは「料金はお問い合わせください」と案内。元画像は両方参照できる。
2. 税10％と「千円未満四捨五入」は料金表原文に沿って記載。自動の合計計算は実装していない。
3. 席数は提供情報どおり「30ボックス」と記載。
4. 人物写真のスタンプは保持し、過去のイベント写真として紹介。在籍者名・人数・開催日を推測していない。
5. ヒーローは生成イメージ。実際の店内は提供写真を使用。
6. 公開先URLは未提供。架空のcanonicalやOGP絶対URLは追加していない。公開URL確定時は`astro.config.mjs`のsite設定と、必要なrobots・sitemapを整える。
7. 既存のpackage.json・package-lock.json・ファビコン・OGP・元写真を上書きしていない。追加依存パッケージなし。

## 確認状況

利用者から「実装後の確認は自分で行うので不要」と指定されているため、以下は実施していない。

- ビルド、型チェック、テスト、実装後の静的検査。
- 開発サーバーの起動、PC・スマートフォンの表示確認、スクリーンショット。
- スクロール・アニメーション・dialog・キーボード・タッチ操作の実機確認。
- 電話・SNS・地図リンクの遷移確認。
- 画像最適化結果の確認、公開・デプロイ・検索エンジンへの反映確認。

## 利用者による確認の際の起動方法

AGENTS.mdに従い、開発サーバーはプロジェクト内で`npm run dev -- --background`を使用。管理は`npm run astro -- dev status`、`npm run astro -- dev logs`、`npm run astro -- dev stop`。

料金の現行性、瓶ビールの適用条件、税の端数処理、イベント写真の掲載範囲、公開先URLについては計画書の確認事項を引き継ぐ。
