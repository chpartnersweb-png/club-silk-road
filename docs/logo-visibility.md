# 公式ロゴとヒーローの視認性調整

2026年10月28日。承認された改善プランに沿ってソースを修正。

- `src/assets/logo.png`を共通のBrandコンポーネントで使用。
- ヘッダーの文字で組んだ店名を、公式ロゴ画像へ変更。スマートフォンメニュー内にも同じ画像を使用。
- ヘッダー・ヒーロー・メニュー内はCSSの白抜き表示。元画像は変更しない。
- フッターは明るい台紙と元の黒いロゴを維持。
- ヒーローの台紙とその余白を外し、ロゴ本体の幅をPCで380〜440px、スマートフォンで最大290pxに拡大。
- 配信用ロゴの画像幅は用途別に指定し、ヒーローでは880px幅を生成して高密度画面を考慮。元の縦横比を保持。
- PCは背景を右方向まで広げ、上部中央を暗くするグラデーションを追加。
- スマートフォンは背景の開始位置と上部のなじませ方を調整。高さの小さい画面用にも配置を分岐。
- ロゴと短いコピーの初回フェード・移動を外し、最初から読める状態にする。背景画像の緩やかなズームは維持。

利用者の指定に従い、変更後のビルド・型チェック・静的検査・ブラウザ表示・アニメーションの確認は実施していない。
